# Ctrl+R переименовывает любую сессию

---
status: accepted
---

`Ctrl+R` доступен для всех сессий, включая отображённые через `Ctrl+G` сессии pi-subagents. Поведение повторяет штатный picker: callback добавляет в JSONL запись `session_info`, после успешной записи воркер обновляет соответствующую строку индекса без полного диффа. Запрет на rename сабагентов отклонён: это была бы неочевидная потеря штатной функции, а сабагентная сессия не является защищённым системным файлом.
