# Холодный старт показывает пустой picker и наполняет его постепенно

---
status: accepted
---

Если индекса ещё нет, `/rf` сразу открывает оригинальный picker с пустым списком; обёртка показывает статус `Index warming up… x/y`. Единственный worker-владелец (ADR-0011) сканирует файлы фоном и постепенно подменяет список через `setSessions`, так что первые подходящие сессии появляются без ожидания полного обхода. Fallback на штатный `/resume` и блокировка picker до bootstrap отклонены: оба возвращают заметный cold-start lag, ради устранения которого создаётся расширение.
