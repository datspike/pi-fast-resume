# Индекс живёт в ~/.pi/agent/pi-fast-resume/index.db

---
status: accepted
---

База индекса хранится в `~/.pi/agent/pi-fast-resume/index.db`, рядом с остальными долгоживущими данными Pi (`pi-session-meta.sqlite`, `sessions.db`). Варианты «кэш в XDG» отклонены: выпадает из существующих бэкапов зеркала агента; отдельный dot-каталог в `$HOME` (путь дохлого session-search) — мусорит домашний каталог. База считается производными данными: полный rebuild — штатный аварийный путь; порченная база пересоздаётся автоматически без диалогов.
