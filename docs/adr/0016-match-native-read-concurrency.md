# Worker читает до 10 JSONL параллельно, как штатный Pi

---
status: accepted
---

Worker обрабатывает до 10 session-файлов одновременно — то же ограничение `MAX_CONCURRENT_SESSION_INFO_LOADS = 10`, которое использует установленный `SessionManager.listAll()`. Это сохраняет проверенную скорость штатного metadata scan. Транзакционные checkpoint-пакеты остаются размером 25 файлов (ADR-0015): чтение параллельное, SQLite-запись пакетная. Уменьшение конкуренции и автонастройка отклонены без измеренных оснований.
