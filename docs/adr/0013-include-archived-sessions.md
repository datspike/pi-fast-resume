# Архивные сессии индексируются и видны в режиме All

---
status: accepted
---

Воркер индексирует JSONL из каталогов `__archive__--…--` наравне с активными сессиями. В режиме All они видны так же, как в штатном `SessionManager.listAll()`; режим Current Folder естественно остаётся ограничен `cwd`. В индекс записывается флаг `archived` для будущей визуальной маркировки, но дополнительный фильтр сейчас не добавляется. Исключение архивов и скрытие по умолчанию отклонены как отклонение от поведения оригинального `/resume`.
