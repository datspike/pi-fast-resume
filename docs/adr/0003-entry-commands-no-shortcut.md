# Вход через команды /rf и /resume-fast, без шортката

---
status: accepted
---

Наш пикер открывается командами расширения `/rf` и `/resume-fast` (два имени одного обработчика). Встроенный `/resume` остаётся нетронутым: удаление пакета полностью возвращает родное поведение. Перехват события `input` для подмены штатного `/resume` отклонён как агрессивная подмена поведения по умолчанию с более хрупким контрактом. Горячая клавиша пока не регистрируется — хоткеи Pi требуют сверки с занятыми биндингами; решение отложено до отдельного запроса.
