# Ctrl+G меняет фильтр только текущего picker overlay

---
status: accepted
---

Каждый новый `/rf` или `/resume-fast` открывает picker с `Agents: hidden`. `Ctrl+G` переключает видимость сабагентных сессий только до закрытия текущего overlay и не записывается в SQLite или настройки Pi. Это повторяет жизненный цикл штатных переключателей picker'а (`sort`, named filter, path display, scope), сохраняет предсказуемый default и не даёт одному случайному нажатию снова засорить будущие списки агентами.
