# Сабагентные сессии скрыты по умолчанию, Ctrl+G их показывает

---
status: accepted
---

Пикер по умолчанию исключает сессии pi-subagents, а `Ctrl+G` переключает режим `Agents: hidden/shown` без чтения диска. Сессия считается сабагентной только при одновременных признаках: `parentSessionPath` задан и имя соответствует `/^[^#]+#[0-9a-f]{8}$/i`. Одного `parentSessionPath` недостаточно: его используют и обычные `/fork`/`/clone`, которые должны остаться в списке. Настройка pi-subagents `Remember agents` не меняется: она отвечает за сохранение transcript и `@handle`-resume, а не за видимость в picker.
