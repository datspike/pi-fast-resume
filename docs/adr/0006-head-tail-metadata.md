# Метаданные только из head/tail, счётчик сообщений приблизительный

---
status: accepted
---

Для нового или изменённого JSONL воркер читает только head (до 64 KiB: header, `cwd`, `id`, created, `firstMessage`) и tail с адаптивным окном 64→256 KiB (последняя полная `session_info` для имени). Полный файл не читается и не JSON-парсится. `messageCount` сохраняется от предыдущей версии индекса и после изменения считается приблизительным; если значения ещё нет, пикер показывает `—`. Точность счётчика — декоративная и не влияет на возобновление, тогда как повторное потоковое чтение активного файла до десятков MiB перечеркнуло бы цель расширения.
