# Ручной полный rebuild запускается через /rf reindex

---
status: accepted
---

`/rf reindex` очищает только таблицы производного индекса и запускает тот же прогрессивный bootstrap с checkpoint-пакетами и показом прогресса `x/y`. JSONL session-файлы команда не изменяет. Если lease диффа удерживает другой Pi-процесс, команда не создаёт второй scan, а показывает понятный статус. Автоматический `size`+`mtime` diff остаётся обычным путём; явная команда нужна для оператора после ручного переноса или восстановления каталога сессий.
