# Сбой воркера не включает штатный /resume

---
status: accepted
---

При ошибке worker thread или индекса `/rf` открывает picker с последним доступным SQLite-индексом и показывает ненавязчивый статус ошибки. Если доступного индекса нет, открывается пустой picker с ясным сообщением; пользователь может запустить `/rf reindex`. Расширение никогда не переключается автоматически на штатный `/resume`: его синхронный scan вернул бы TUI-lag именно в аварийный момент. Ошибка не должна лишать пользователя доступных старых результатов.
