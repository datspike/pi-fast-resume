# Ленивый воркер на первую команду, остановка сессией

---
status: accepted
---

Worker thread создаётся только при первом вызове `/rf` или `/resume-fast` в Pi-сессии и завершается на `session_shutdown`. Пока пикер не нужен, расширение не занимает память, не обходит файлы и не конкурирует за SQLite с другими Pi-процессами. При каждом открытии пикера живой воркер запускает фоновый дифф, а список немедленно показывается из индекса (ADR-0002). Автостарт на `session_start` и периодический таймер отклонены: это снова создаёт скрытую фоновую нагрузку во всех Pi-процессах. Пересоздание воркера на каждый вызов отклонено: оно лишает тёплого соединения с индексом без пользы.
