# Ctrl+D повторяет штатное удаление сессии

---
status: accepted
---

`Ctrl+D` сохраняет оригинальную семантику `SessionSelectorComponent`: требуется подтверждение; текущую активную сессию удалить нельзя; сначала вызывается `trash <path>`, а при его отсутствии или ошибке выполняется необратимый `unlink`. После успешного удаления воркер удаляет сессию из индекса локально. Режим «только trash» и отключение Ctrl+D отклонены: оба не соответствуют требованию повторить штатный `/resume` максимально точно.
