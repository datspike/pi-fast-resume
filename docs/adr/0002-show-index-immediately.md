# Показ индекса сразу, дифф в фоне

---
status: accepted
---

При открытии пикера список собирается из SQLite-индекса мгновенно, без ожидания воркера. Воркер при этом запускает дифф; по завершении список тихо обновляется через `setSessions`, и пользователь видит актуальное состояние через несколько секунд. Сознательно принятый компромисс: свежесозданная или переименованная сессия может отсутствовать/иметь старое имя в течение времени диффа — расхождение самоликвидируется. Блокирующее ожидание отклонено: оно убивает смысл проекта и делает холодный первый проход (минуты на корпусе ~3050 файлов) неприемлемым.
