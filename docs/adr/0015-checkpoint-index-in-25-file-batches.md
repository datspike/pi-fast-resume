# Worker фиксирует индекс пакетами по 25 файлов

---
status: accepted
---

Во время cold bootstrap и диффа worker собирает метаданные потоковым чтением, затем коммитит их в SQLite транзакциями по 25 файлов. После каждого коммита готовые строки уже доступны picker'у, прогресс `x/y` отражает сохранённые результаты, а аварийное завершение Pi теряет максимум незакоммиченный пакет. При новом запуске worker делает дешёвый `stat`-diff и повторно читает только отсутствующие или изменившиеся файлы. Один commit в конце отклонён как потеря прогресса; commit на файл — как лишняя WAL-нагрузка.
